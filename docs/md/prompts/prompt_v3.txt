Use case: ui-mockup. Windows 11 데스크톱 유틸리티 목업, 한국어 라벨, 플랫하고 깔끔한 스타일. 1536x1024 가로.

[위쪽 절반: 게임 화면 + 디버그 오버레이]
바탕화면 위에 하얀 'Bongo Cat' 고양이 3마리. 가로 간격도 불규칙하고 높이도 서로 다름:
'리네' 고양이는 작업표시줄 바로 위(낮게), '철수' 고양이는 화면 중간 높이로 떠 있음, '민지' 고양이는 리네보다 조금 높게, 철수와 가로로 꽤 가깝게.
각 고양이 바로 아래 흰 이름 태그('리네', '철수', '민지'). 각 고양이 머리 위에는 선물 아이콘 2개가 좌우로: 왼쪽 선물 상자+'100', 오른쪽 선물 상자+'1000' (총 6개). 아이콘과 이름표의 상대 위치는 세 고양이 모두 똑같음.
'리네' 고양이 왼쪽 위 흰 말풍선 '야옹 야옹', '민지' 위 말풍선 '안녕하세요'.
오버레이: 고양이 3마리 전체를 감싸는 회색 점선 큰 사각형 1개, 왼쪽 위 라벨 '감지 영역'. (가로 띠는 그리지 않음)
각 이름표를 기준점으로 표시: 이름표 위 작은 점, 그 점에서 자기 고양이의 두 아이콘 박스까지 가는 얇은 연결선 2개, 말풍선에서 화자 이름표까지 파란 점선 연결선.
'리네', '민지': 이름표와 아이콘 박스 초록, 아이콘 라벨 '대상 0.93'. '철수': 빨강, 아이콘 라벨 '대상 아님 0.91'.
오른쪽 위 작은 반투명 정보 상자: '고양이 3 · OCR 0회 (캐시) · 12ms · CPU 1%'.

[아래쪽 절반: 'Bongo Cat 헬퍼' 제어 패널 창 (Windows 기본 창 모양)]
상단 버튼 줄: '시작', '정지(F12)', '보정', 'OCR 테스트', 체크된 체크박스 'dry run(연습 모드)', 오른쪽에 노란 배지 '연습 모드 · 실행 중'.
왼쪽 열: '선물 대상' 목록(리네, 민지) + 추가/삭제 버튼, 아래 통계 '선물 12', '채팅 48'.
오른쪽 열: 탭 2개 '판단 로그' / '채팅 기록' 중 '채팅 기록' 탭 선택됨.
채팅 기록 탭: 날짜 선택 '2026-10-12', 화자 필터 드롭다운 '전체', 검색창 '검색', 버튼 'MD로 내보내기'.
표 열: 시간 | 화자 | 내용. 행: '14:02:12 | 리네 | 야옹 야옹', '14:02:15 | 민지 | 안녕하세요', '14:03:40 | 철수 | 선물 고마워'.
하단 상태줄: '저장: data/chat.db · 오늘 48건'.

Text (verbatim): 작은따옴표 안의 한국어 문구를 정확히 그대로.
Avoid: 가로 점선 띠, 영어 라벨, 고양이당 아이콘 1개, 세 고양이를 같은 높이로 정렬, 워터마크.
