Use case: ui-mockup. Windows 11 데스크톱 유틸리티 목업, 한국어 라벨, 플랫하고 깔끔한 스타일. 1536x1024 가로.

[위쪽 절반: 게임 화면 + 디버그 오버레이]
작업표시줄 바로 위에 하얀 'Bongo Cat' 고양이 3마리가 가로 한 줄에 서로 불규칙한 간격으로 흩어져 있음(왼쪽 가까이 1마리, 가운데보다 오른쪽에 2마리가 비교적 가깝게). 각 고양이 아래 흰 이름 태그: '리네', '철수', '민지'.
각 고양이 머리 위에는 선물 아이콘이 반드시 2개씩 좌우로 나란히 있음: 왼쪽 선물 상자 + 숫자 '100', 오른쪽 선물 상자 + 숫자 '1000' (고양이 3마리 x 2개 = 아이콘 총 6개).
'리네' 고양이 왼쪽 위에 흰 말풍선 '야옹 야옹', '민지' 위에 말풍선 '안녕하세요'.
점선 가로 띠 3개와 라벨: '채팅 영역'(말풍선 높이), '아이콘 영역'(선물 아이콘 높이), '이름 영역'(이름 태그 높이).
'리네'와 '민지'의 아이콘 4개는 초록 박스 + 라벨 '대상 0.93' 같은 매칭점수, 이름 태그도 초록 테두리.
'철수'의 아이콘 2개는 빨간 박스 + 라벨 '대상 아님 0.91', 이름 태그도 빨간 테두리.

[아래쪽 절반: 'Bongo Cat 헬퍼' 제어 패널 창 (Windows 기본 창 모양)]
상단 버튼 줄: '시작', '정지(F12)', '보정', 'OCR 테스트', 체크된 체크박스 'dry run(연습 모드)', 오른쪽에 노란 배지 '연습 모드 · 실행 중'.
왼쪽 열: '선물 대상' 목록(리네, 민지) + 추가/삭제 버튼, 아래 통계 '선물 12', '채팅 48'.
오른쪽 열: 탭 2개 '판단 로그' / '채팅 기록' 중 '채팅 기록' 탭이 선택됨.
채팅 기록 탭: 상단에 날짜 선택 '2026-10-12', 화자 필터 드롭다운 '전체', 버튼 'MD로 내보내기'.
표 열: 시간 | 화자 | 내용. 행 예: '14:02:12 | 리네 | 야옹 야옹', '14:02:15 | 민지 | 안녕하세요', '14:03:40 | 철수 | 선물 고마워'.
하단 상태줄: '저장: data/chat.db · 오늘 48건'.

Text (verbatim): 위에 작은따옴표로 적힌 한국어 문구를 정확히 그대로.
